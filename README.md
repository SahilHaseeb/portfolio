# 🌐 Developer Portfolio

> **Live Website:** [https://haseebsahil-portfolio.onrender.com](https://haseebsahil-portfolio.onrender.com)

A modern, responsive personal portfolio showcasing projects in **Python**, **Data Science**, **Machine Learning**, **AI**, and **Web Development**.

---

## ✨ Key Highlights

- **⚡ Fast & Dependency-Free:** Built with pure semantic HTML5, Vanilla CSS design tokens, and modular ES6 JavaScript.
- **📱 Fully Responsive:** Custom fluid layouts tailored for Mobile, Tablet, Laptop, and 4K displays.
- **🎨 Modern Dark UI:** Glassmorphism surfaces, subtle glow gradients, and accessible high-contrast typography.
- **📊 Dynamic Showcase:** Data-driven filterable projects section, interactive learning journey roadmap, and accessible contact form.
- **🚀 Static Deployment:** Deployed and hosted continuously via Render.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, Vanilla CSS3 (Custom Properties & Fluid Typography), JavaScript (ES Modules)
- **Design System:** Dark Mode, Glassmorphism, CSS Grid & Flexbox
- **Deployment:** Render Static Hosting
